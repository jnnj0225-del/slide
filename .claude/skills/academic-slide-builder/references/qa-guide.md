# 想定問答の作り方

## 方針
- 回答は**原稿・解析結果に根拠がある内容**に限る。根拠が無い質問は、回答案の代わりに「データに無いため、解析追加が必要」「口頭では限界として述べる」といった対応方針を書く
- 質問は聞かれやすい順に並べ、1つ2〜3文の回答にする(発表の場で話せる長さ)
- 数値を使う回答は、付録スライドのページ番号を併記する

## 質問カテゴリ(各カテゴリから拾う)
1. **対象・デザイン**: 選択バイアス、除外基準、期間・施設差、サンプルサイズ
2. **方法・統計**: 交絡の調整方法、多変量の共変量の選び方、欠測、感度分析、ランドマーク/IPW の妥当性
3. **結果の解釈**: 有意差が出なかった理由、サブグループの傾向、既存試験との違い
4. **臨床的意義**: 診療が変わるか、どの患者に適用できるか
5. **限界**: 後ろ向き、一般化可能性、追跡期間
6. **今後**: 前向き検証、追加解析、共同研究の計画

## 出力形式(Word)
表: `# / 質問 / 回答案 / 根拠(原稿のページ・付録スライド番号) / 要追加解析?`
先頭に、最も聞かれそうな質問トップ5をまとめる。
