# 口演スライドの構成と時間配分

## 枚数の目安

発表時間(質疑を除く)に対し、**1分あたり約1枚**を上限の目安とする。表紙・COI は時間に含めない。

| 発表時間 | 本編の枚数目安 | 配分の例 |
|---|---|---|
| 5分 | 5〜6枚 | 背景1 / 目的1 / 方法1 / 結果2 / 結論1 |
| 7分 | 7〜9枚 | 背景1 / 目的1 / 方法1 / 結果3〜4 / 考察・限界1 / 結論1 |
| 10分 | 10〜12枚 | 背景1〜2 / 目的1 / 方法1〜2 / 結果4〜5 / 考察1〜2 / 結論1 |
| 12分 | 12〜14枚 | 同上に結果・考察を各1枚追加 |

学会ごとに時間は異なるため、必ず持ち時間を確認してから逆算する。

## 流れ

1. **表紙**: 演題名、演者(所属)、共同演者、学会名(発表日は任意)
2. **COI開示**: 学会指定の様式に従う(conference-etiquette.md 参照)
3. **背景**: 臨床的な問い → 既存知見の不足(ギャップ)の順で、2〜3点に絞る
4. **目的**: 1文。主要評価項目と対応させる
5. **方法**: 対象(期間、施設、適格・除外基準)、データ、評価項目、統計解析。倫理審査の記載もここに入れる
6. **結果**: ①対象患者背景 → ②主要評価項目 → ③副次評価・サブグループ・多変量 の順
7. **考察**: 結果が意味すること、既存知見との位置づけ。2〜3点
8. **限界**: 後ろ向き、選択バイアス、サンプルサイズ等。原稿の記載に沿う
9. **結論**: 目的に対応した答えを2〜3行で。結果を超える主張はしない
10. **付録**: 想定質問への補足

## 結果スライドのタイトル例

悪い例: 「生存解析」「多変量解析」
良い例: 「A群はB群より無増悪生存期間が長かった」「X は独立した予後因子であった」

差が有意でない場合は「有意差は認めなかった」と書く。「差がなかった」と断定しない。

## 図表の扱い

- 1スライド1図表を基本とする
- KM曲線: リスク数表(at-risk)、群ごとの n、HR(95%CI)、P値、軸ラベル(単位)を確認する。無ければ解析者に再出力を依頼する旨を報告する
- 表: 全項目を載せず、主要行だけ抜き出す。全体表は付録へ
- 画像を引き伸ばして解像度を落とさない
- 数値の桁数は全スライドで統一する(例: 中央値は小数第1位、P値は有効数字の規則を統一)
