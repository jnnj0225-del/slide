# ポスター作成ガイド

## 先に確認すること
- **学会指定のサイズと向き**(縦×横 cm、貼付可能領域、演題番号のスペース)。指定が無ければ本人に聞く。推測で決めない
- 提出形式(.pptx / PDF / 印刷持参)
- 言語

## .pptx でのサイズ設定
- pptxgenjs の `defineLayout` で指定サイズ(インチ)にカスタム設定する。cm → inch は `cm / 2.54`
- **PowerPoint のスライドサイズ上限は 56インチ(約142cm)**。超える場合は半分(50%)のサイズで作り、印刷時に拡大する旨を本人に伝える
- 解像度: 図は拡大印刷に耐える大きさの元画像を使う。低解像度なら報告する

## レイアウト
- 上部に演題名・演者・所属・COI(学会規定の位置)・演題番号用の余白
- 基本は3〜4カラム、**読む順番が分かる**配置(番号や矢印を使う)
  - 背景/目的 → 方法 → 結果 → 結論 の順
- 文字量は口演より多少多くてよいが、**結果の図表を面積の過半**にする
- 結論は目立つ囲みで、全体の下部または右端に置く
- 本文は遠くから読めるサイズにする(目安: 本文24pt以上、見出し36pt以上。指定サイズが大きい場合はさらに大きく)
- 各図表にキャプション(結論の一文)を付ける
- QRコード(論文・詳細データへのリンク)は本人が希望した場合のみ

## 内容
- 口演と同じ統計チェック(stats-checklist.md)と学会作法(conference-etiquette.md)を適用する
- 文章は箇条書き中心にし、冗長な説明は削る
- 質問が多いと予想される図表は大きめに配置する

## 納品時の確認
- 画像化して、指定サイズでの全体レイアウトと文字のはみ出しを確認する
- 印刷時の色・余白(裁ち落とし)は印刷所の仕様に依存するため、本人に確認を促す
