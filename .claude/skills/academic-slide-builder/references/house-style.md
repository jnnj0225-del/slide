# ハウススタイル(永山 洵 先生のスライド書式)

学会口演・研究会の症例提示とも、特に指定がなければこの書式で作る。
コードは `scripts/nu_style.py`(python-pptx 用ヘルパー)。`cover()` `header()` `band_header()`
`panel()` `table()` `finish()` を使えば、以下の仕様が自動で入る。

## 基本
- 16:9(13.333 × 7.5 in)
- フォント: **メイリオ**(和文・欧文とも)
- **文字は基本すべて中央揃え**(タイトル、本文、表のセル、パネル)。例外は時系列(タイムライン)のように左揃えでないと読みにくいものだけ
- スライドタイトル: **40pt 以上**、太字、中央。タイトルは短く(画像スライドは「腹部造影CT」「胸部CT」など **modality 名のみ**。所見は本文側に書く)
- 本文: **20pt 以上**。バランスを見て入る限り大きく(22〜28pt が目安)。出典・注記のみ 14pt 可
- 文字量が入らないときは、フォントを下げずに文言を削る/スライドを分ける

## 配色
| 用途 | 色 |
|---|---|
| 基調色(表紙背景、DP の帯、表ヘッダー、区切り線) | 水色寄りの青 `#1F80C8` |
| タイトル文字 | `#135C96` |
| パネル背景 | `#EAF4FC` |
| アクセント(タイトル下の線、強調ボタン、画像の矢印) | オレンジ `#E8731A` |
| 異常値・重要所見 | 赤 `#C00000` |

## 表紙
- 青背景。メインタイトルのみ(サブタイトル・会名の前置きは入れない)
- **所属・氏名は中央揃え**
- 会名・日付(例: 東海RCC Treatment Consensus Forum / 2026.11.27)は**右上の隅**に小さく
- 名大医学部ロゴ(白抜き、`assets/nu_med_logo_white.png`)を右下

## 各スライド共通
- タイトル下にオレンジ+青の二重線
- **右下に名大医学部ロゴ**(`assets/nu_med_logo_color.png`)。「名古屋大学大学院医学系研究科 泌尿器科学」の文字フッターは入れない
- 左下にページ番号
- 右上に小さく区分ラベル(例:「症例提示(患者背景) ご発表:永山先生」)

## 症例提示スライドの書き方
- 患者背景・現病歴は**表にせず**、中央揃えの文章で(年齢・性別・主訴を大きく1行目に)
- 胸部CTなど病期が決まる画像のスライドに、**cTNM と IMDC 分類**を右側パネルで示す
- 薬物治療方針(名大指針など)は、**薬物の話が出る DP の直前**に置く
- 患者の氏名・ID・生年月日・標本ラベルが写った画像は使わない(切り抜き・塗りつぶしてから使う)

## ロゴの出典
名古屋大学大学院医学系研究科・医学部医学科 公式サイト(https://www.med.nagoya-u.ac.jp/medical_J/)のロゴ画像。
