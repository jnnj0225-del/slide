# 統計記載チェックリスト

スライド生成後、全スライドに適用する。**不足は創作せず、`[要確認]` として報告する。**

## 対象・デザイン
- [ ] 研究デザイン(後ろ向き/前向き、単施設/多施設)が方法に明記されている
- [ ] 対象期間、施設数、適格・除外基準がある
- [ ] 解析対象数(n)が、フローまたは本文で追える。除外後の人数が結果の n と一致する
- [ ] 主要評価項目と副次評価項目が方法に定義されている(評価基準: RECIST 等)

## 結果の記載
- [ ] 連続変数: 中央値(範囲または IQR)か 平均±SD かが明記されている
- [ ] 群間比較: 効果量(HR/OR/差)と **95%CI** と P値が揃っている
- [ ] P値は検定名と両側/片側を方法に記載。多重比較をしているなら補正の有無
- [ ] 観察期間(追跡期間の中央値)が記載されている
- [ ] 生存解析: 手法(Kaplan-Meier、log-rank、Cox)、リスク数表、打ち切りの扱いがある
- [ ] 多変量解析: 調整した共変量の一覧、イベント数に対する共変量数が過剰でない
- [ ] 特殊な手法の記載: ランドマーク解析(起点)、IPW・傾向スコア(使った変数と評価)、競合リスク(競合イベントの定義)
- [ ] 欠測データの扱いが述べられている(該当する場合)

## 表現
- [ ] 略語は初出で正式名称を併記(例: IMDC、PFS、OS)
- [ ] 単位が統一されている
- [ ] 「有意差なし」を「差がない」と読み替えていない
- [ ] 結論が結果の範囲を超えていない(後ろ向き研究で因果を断定していない)
- [ ] 限界スライドに、研究デザイン由来の限界が書かれている

## 突合
- [ ] スライド上の全数値が、原稿または解析結果と一致する(不一致は報告)
- [ ] 図中の n・HR・CI と、本文スライドの数値が一致する
